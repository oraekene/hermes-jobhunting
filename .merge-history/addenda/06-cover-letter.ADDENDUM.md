# 06-cover-letter — Addendum: a narrative shape branch for `profile_stage: first_time`

This skill's default opener leans on years-of-experience framing
("in my N years doing X..."). For `profile_stage: first_time`, that
framing doesn't fit and shouldn't be forced — the narrative shifts to
what's actually true and still genuine: what the person has built,
learned, and cares about, and why it points at this specific role.
Draws on the same widened evidence sources `09-risk-tactics-gate/
ADDENDUM.md` and `05-resume-customizer/ADDENDUM.md` already use for
this `profile_stage` — school projects, volunteer work, and
`memory/interests-profile.md` entries are legitimate hook material
here, not a fallback used only when nothing better exists.

Same fidelity discipline throughout — a genuine interest used as a
"why this role" hook still only works when it's actually true, same as
any other claim this skill drafts.

## Wiring: `21-output-templates`

Before drafting from `cover-letter-formula.md`'s base default, check
`shared/output-templates.yaml` for any `artifact_type: cover_letter`
entry whose `trigger_conditions`/`recipient_targeting` match the
current company/role. No match → base default runs unchanged. One
match → use it, note which template in the draft. Multiple matches →
ask Kene which one, per `21-output-templates/SKILL.md`'s own selection
rule.
