# 09-risk-tactics-gate — Addendum: wider evidence tiers, same rigor

For `target-profile.yaml`'s `profile_stage: first_time`: this gate's
job doesn't change — every claim still needs to trace to something
real and specific before it clears. What changes is which files count
as legitimate places for that evidence to live. Alongside the STAR bank
and `domain-knowledge.md`, this gate now also checks claims against:
school records/coursework, documented extracurricular or volunteer
work, and `memory/interests-profile.md` entries — exactly the widened
Phase 1 source list `07-context-architect/ADDENDUM.md` describes for
this `profile_stage`.

**The bar itself is explicitly unchanged.** "I organized the fundraiser"
still needs the number that makes it real, the same way an unquantified
resume bullet would fail this gate regardless of `profile_stage`. What
this addendum adds is acceptance of a wider set of *sources* for that
same standard of evidence — a first-time applicant's realistically
available evidence is different in kind from an experienced applicant's,
not lower in the standard it has to meet.

See `onboarding/references/starting-out-track.md` for why this shift
exists and everywhere else it touches.
